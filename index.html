Sauvegarde

Comment obtenir l'identifiant client Google ?
  1. Sur console.cloud.google.com, créez un projet.
  2. « API et services » → « Bibliothèque » : activez Google Drive API.
  3. « Écran de consentement OAuth » : type « Externe », nom Etchnote, puis ajoutez votre adresse Gmail comme « utilisateur test ».
  4. « Identifiants » → « Créer des identifiants » → « ID client OAuth » → « Application Web ». Dans « Origines JavaScript autorisées », ajoutez https://julien67890.github.io.
  5. Copiez l'identifiant (il finit par .apps.googleusercontent.com) dans le champ ci-dessus.

Seul le fichier « Etchnote - sauvegarde.json » créé par l'application est accessible. Le reste de votre Drive reste invisible pour elle.
